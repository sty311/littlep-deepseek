# Changelog

## Source-ready packaging

- Clean original-source layout, runtime placeholder config, checked patch/install/rollback tools, synthetic fixtures, local verification and CI template.
- Public supervisor launch handshake is serialized to avoid a concurrent-start port-probe race found by clean-copy testing. Private stable/device code is unchanged.
- No publication or new device deployment performed during packaging.
