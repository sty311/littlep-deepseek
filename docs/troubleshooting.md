# Troubleshooting

| Symptom | Check / action |
|---|---|
| Unsupported device / hash | Stop; compare read-only identity and hashes. Do not patch guessed offsets. |
| Authentication required | Obtain authorized shell access independently; no password/bypass is supplied here. |
| Compiler rejected | Supply the exact compiler hash; no approximate QuickJS version accepted. |
| Port occupied | Inspect service status; supervisor never kills an unrelated process. |
| API authorization/rate error | Check private configuration/account; never paste keys or request headers in an issue. |
| Search failure | Status reports failure; current tool-loop can answer from available information without claiming fresh search success. |
| Reasoning/answer not displayed | Confirm compatible page wrapper, exact app version and bridge health. Restore the verified backup instead of blind changes. |
| Formula oddities | Display conversion covers tested chemistry/math forms, not all LaTeX packages. Report a synthetic minimal expression. |
| Restart clears conversation | Expected: sessions are memory-only. |
| ADB missing after OS restart | The stock USB/UI policy may require manually enabling ADB again; bridge autostart is independent. |

`status.sh` displays process identity, health and loopback address. Logs are bounded, but even hashes/timing can reveal usage patterns; review before sharing. Do not attach firmware, original/modified vendor code, personal scans, full logs or account data. See [SECURITY.md](../SECURITY.md).
